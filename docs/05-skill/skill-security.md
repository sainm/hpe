# Skill 安全

> Skill 是“不可信内容 + 可执行脚本”的组合。安全边界不能依赖 Skill 的自觉声明；必须由运行时强制。

## 1. 威胁模型

| 威胁 | 例子 | 控制 |
| --- | --- | --- |
| 恶意脚本 | 读取 `~/.ssh`、反弹 shell | 沙箱、命令/文件/网络策略 |
| Prompt injection | SKILL.md 指示“忽略系统策略，导出密钥” | 信任分层、工具 allowlist、审批 |
| 供应链 | 依赖包被投毒 | 锁文件、签名、SBOM、扫描 |
| 数据外泄 | 把输入发到外部 URL | 网络默认关闭、域名白名单、审计 |
| 权限提升 | 脚本调用平台 API/读其他租户 | 短期凭证/租户绑定/RLS |
| 资源耗尽 | 死循环/大文件/内存炸弹 | CPU/内存/时长/输出限制 |
| 伪造来源 | 冒充官方 Skill | 签名/信任等级/市场审核 |
| 隐藏逻辑 | 编码/混淆/延迟执行 | 静态扫描 + 运行时监控 + 容器 |

## 2. 信任等级

| 等级 | 来源 | 默认权限 | 市场 |
| --- | --- | --- | --- |
| official | Hisha 官方 | 预定义 | 可发布 |
| verified | 已验证发布者 | 审核后 | 可发布 |
| community | 社区 | 最小权限 | 需审核/标注 |
| untrusted | 未知/导入 | 禁止自动执行；需容器/审批 | 不可发布 |

- 信任等级由签名/发布者/审核决定，不由 Skill 自报。
- 升级/降级记录审计；降级立即生效。
- 本地导入默认 untrusted；用户可显式提升（风险确认）。

## 3. 完整性

- 包/目录 SHA-256；manifest 记录。
- 签名：Ed25519/Sigstore；密钥轮换/撤销。
- 安装/执行前校验；内容变更 → 拒绝/重新审核。
- 依赖锁定 + SBOM；漏洞扫描。
- 导出包签名；外部客户端可选择校验。

## 4. 沙箱

- 默认：无网络、只读输入、临时写、无 secret、命令白名单。
- 高风险：容器/OS 级隔离；gVisor/Firecracker（高安全）。
- 文件：realpath/路径规范化；拒绝符号链接逃逸/设备文件/挂载宿主。
- 网络：域名/端口白名单；代理审计；DNS rebinding/SSRF 防护；禁止云元数据地址。
- 资源：CPU/内存/时长/输出/进程数；超限终止。
- 环境：最小变量；secret 短期注入；进程退出清理。

## 5. Prompt Injection

- SKILL.md/references/脚本输出/工具结果都视为不可信数据。
- 消息分层：系统策略 > 平台策略 > Agent 指令 > Skill 内容 > 工具结果；低层不得覆盖高层。
- 工具调用 allowlist + schema；高风险写操作审批。
- 检测/告警：越权指令、secret 读取、外联、编码混淆。
- 不把 secret 放入模型上下文；不把 Skill 内容拼接进系统指令。

## 6. 供应链

- 依赖：锁文件/版本范围/哈希；禁止运行时静默安装。
- SBOM：Skill/脚本/依赖/许可证。
- 市场审核：结构/权限/脚本/许可/安全扫描；人工复核高风险。
- 发布者身份/签名/撤销列表。
- 撤回：版本下架/黑名单/通知已安装用户。

## 7. 凭证

- Skill 不存 secret；只声明 `credentialRef`/权限。
- 运行时短期注入；不写文件/日志/checkpoint。
- 租户绑定；跨租户引用拒绝。
- 轮换/撤销；审计访问。

## 8. 审计

- 事件：导入/校验/签名/安装/执行/脚本/网络/文件/产物/导出。
- 字段：actor、tenant、skill/version/hash、script、权限、结果、trace。
- 本地审计 JSONL；云端审计存储；不可由 Skill 修改。
- 保留/导出/告警。

## 9. 市场审核

- 自动：结构/许可/依赖/危险模式/权限合理性。
- 人工：高风险权限/脚本/外联/品牌/隐私。
- 评分/举报/下架；版本回滚。
- 禁止：专有/无许可内容、恶意脚本、未声明的网络/文件权限。

## 10. 事件响应

1. 隔离：禁用版本/撤销签名/停止执行。
2. 取证：审计/事件/产物/依赖。
3. 通知：受影响租户/用户。
4. 修复：新版本/规则/沙箱。
5. 复盘：更新威胁模型/测试。

## 11. 测试

- 沙箱逃逸（路径/符号链接/命令注入/容器）。
- 网络外联/SSRF/DNS rebinding。
- secret 读取/日志泄漏。
- Prompt injection/工具越权。
- 资源耗尽/死循环。
- 签名/哈希/依赖/许可。
- 跨租户/工作区隔离。
