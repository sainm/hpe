# Agent Center

> Phase 4 实现说明：当前本地版使用单页 `/agents`，通过左侧列表与「テスト / 設計 / セッション」标签切换；设计器以 `hpa.agent/v1` JSON 编辑并创建不可变版本。下方是完整产品形态的目标规格，尚未实现的独立 `/agents/:id` 子路由、表单化模型设置与复杂过滤不在本地 MVP 范围内。
>
> 路由：`/agents`（列表）、`/agents/:id`（详情/编辑）、`/agents/:id/test`（测试）、`/agents/:id/sessions`（会话）。默认日语。

## 1. 列表

- 视图：表格/卡片；默认表格（高密度）。
- 列：名称、状态（draft/published/disabled）、版本、模型、Skills/Tools 数、最近运行、成功率、所有者、更新时间。
- 过滤：状态/模型/所有者/标签；搜索。
- 操作：创建、导入、克隆、发布、禁用、删除（影响检查）。
- 空状态：创建/模板/文档。
- 行点击 → 详情；更多菜单 → 测试/会话/版本。

## 2. 详情/设计器布局

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Agents | 名称 [Draft] | 保存 テスト 公開 | バージョン      │
├──────────────┬───────────────────────────────────────────────┤
│ 設定ナビ     │ フォーム                                      │
│ 基本情報     │ 名前/説明/システム指示                         │
│ モデル       │ モデル/温度/最大トークン                       │
│ スキル       │ Skills 選択/権限                              │
│ ツール       │ Tools/MCP/Workflow アクセス                    │
│ メモリ       │ 短期/長期/保持                                 │
│ 予算         │ ステップ/ツール/トークン/コスト/時間           │
│ 承認         │ 承認ポリシー/リスク                            │
│ 出力         │ 構造化出力 schema                              │
├──────────────┴───────────────────────────────────────────────┤
│ 右パネル: プレビュー / 検証 / 差分 / ドキュメント            │
└──────────────────────────────────────────────────────────────┘
```

- 左侧设置导航；主区表单；右侧预览/校验（可折叠）。
- 顶部：保存/测试/发布/版本；脏状态/冲突。

## 3. 表单字段

| 组 | 字段 |
| --- | --- |
| 基本 | 名称、描述、系统指令（Monaco）、标签、头像 |
| 模型 | Provider/Model、温度、Top-P、最大输出 token、fallback |
| Skills | 选择 SkillVersion；权限/依赖；启用/禁用 |
| Tools | 内置/Connector/Workflow/MCP；风险/审批/预算 |
| Workflow | 可调用的 WorkflowVersion；输入/输出合同 |
| 记忆 | 短期/长期；保留；可删除；租户隔离 |
| 预算 | maxSteps/maxToolCalls/timeout/tokens/cost；超限行为 |
| 审批 | 风险等级→审批人/SLA/升级；工具级覆盖 |
| 输出 | JSON Schema；示例；严格模式 |
| 安全 | 工具 allowlist；沙箱；数据分类；提示注入防护 |

交互：

- 系统指令/输出 schema 用 Monaco；支持变量/工具提示。
- Skills/Tools 选择器：搜索/版本/权限/风险；显示依赖。
- 预算/审批：默认安全值；高风险需确认。
- 变更显示“权限新增/审批变化”摘要。
- 发布：校验（模型/工具/Skill/MCP 可用、权限、预算、输出 schema）；不可跳过。

## 4. 测试控制台

```text
┌──────────────────────────────┬───────────────────────────────┐
│ 入力 (JSON/フォーム)         │ 実行トレース                  │
│ ユーザーメッセージ           │ 計画 → ツール → 観察 → 回答   │
│ モック設定                   │ ステップ/コスト/所要時間      │
│ [実行] [停止]                │ ツール入出力/承認             │
└──────────────────────────────┴───────────────────────────────┘
```

- 输入：消息/结构化输入；测试用例保存。
- Mock：模型响应、工具结果、错误、延迟；不调用真实外部系统。
- 运行：流式；可取消；预算/步数显示。
- 轨迹：计划/工具调用/观察/审批；敏感字段脱敏。
- 断言：输出 schema/字段/工具调用顺序；通过/失败。
- 回归：保存用例；版本变更后重跑。

## 5. 会话/观测

- 会话列表：状态、AgentVersion、开始/结束、步数/成本、结果。
- 详情：消息/计划/工具调用/审批/checkpoint；恢复/取消（策略）。
- 指标：成功率/延迟/成本/工具错误/审批等待。
- 过滤：时间/用户/版本/状态。
- 导出：JSON/审计（权限）。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 空 | 创建/模板/导入 |
| 加载 | 骨架 |
| 权限 | 403 + 请求访问 |
| 只读 | 已发布/无权限；隐藏编辑 |
| 冲突 | 版本冲突；对比/另存 |
| 离线 | 本地模型可用；云模型禁用 |
| 测试中 | 流式/停止/预算 |
| 发布中 | 校验/错误列表 |

## 7. 窄屏（607px）

- 设置导航变 Tabs/下拉；表单单列。
- 测试控制台上下分栏；轨迹全屏可切换。
- 顶部只保留返回/名称/测试/菜单。
- 工具/ Skill 选择器全屏；触控 ≥44px。

## 8. 验收

- 创建→配置→测试→发布→运行闭环。
- 预算/步数/工具限制生效；超限可解释。
- Skill/MCP/Workflow 调用权限正确；审批触发。
- 测试 mock 不触达真实外部系统。
- 三语/窄屏/键盘/屏幕阅读器。
- 无硬编码文案。
