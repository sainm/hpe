# Approval Center 与其他页面

> 包含 Approval Center、Overview、Connections、Capability Registry、Settings 的页面规格。默认日语。

## 1. Approval Center

路由：`/approvals`、`/approvals/:id`。

### 列表

- 视图：表格；默认“待我审批”。
- 列：状态、风险、类型（Workflow/Agent/MCP/Skill）、请求者、执行/工具、租户/项目、创建时间、SLA 剩余、审批人。
- 过滤：状态/风险/类型/项目/请求者/时间；搜索 ID/标题。
- 排序：SLA/创建时间/风险。
- 批量：仅低风险可批量批准（可配置）；高风险逐条。
- 空状态：无待办/查看历史。

### 详情

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Approvals | 退款审批 [High] | 承認 却下 委任 | SLA 12h     │
├──────────────────────────────┬───────────────────────────────┤
│ 概要                         │ 判断フォーム                  │
│ 请求者/実行/ツール           │ 承認/却下 + コメント          │
│ パラメータ/影響/リスク       │ 条件/追加確認                 │
│ ポリシー/理由                │                               │
├──────────────────────────────┴───────────────────────────────┤
│ 実行コンテキスト/ログ/監査/関連承認                          │
└──────────────────────────────────────────────────────────────┘
```

字段：

- 标题/类型/风险/状态/SLA/创建/到期。
- 请求者/Agent/Workflow/MCP 客户端；租户/项目。
- 参数摘要/影响（金额/对象/环境）；敏感字段脱敏。
- 策略/触发原因；审批人/组；委派链。
- 表单（schema 生成）：decision/comment/条件。
- 关联执行/工具调用/审计/trace。

操作：

- 批准/拒绝/委派/请求补充信息；step-up（高风险）。
- 批准后执行恢复；拒绝按策略；超时升级/拒绝。
- 不可由请求者自批（可配置）；不可绕过。
- 批量限制；审计。

状态：待审批/已批准/已拒绝/超时/已取消/已委派；SLA 颜色/文本。

## 2. Overview

路由：`/`。

```text
┌──────────────────────────────────────────────────────────────┐
│ 概要 | 工作区/项目 | 期間                                    │
├──────────┬──────────┬──────────┬──────────┬─────────────────┤
│ 実行数   │ 成功率   │ 承認待ち │ コスト   │ Worker/Local    │
├──────────────────────────────────────────────────────────────┤
│ 最近の実行 | 失敗/アラート | 承認待ち | 最近の Workflow     │
├──────────────────────────────────────────────────────────────┤
│ クイック: 新規 Workflow / Skill / MCP / AI 生成              │
└──────────────────────────────────────────────────────────────┘
```

- 指标卡：执行数/成功率/审批/成本/Worker；时间范围。
- 近期执行/失败/审批/告警；点击跳转。
- 快速操作；空状态引导。
- 权限：只显示可见范围。
- 离线（Local）：本地统计；云指标禁用。

## 3. Connections

路由：`/connections`。

- Tabs：Connectors / Connections / Credentials。
- Connectors：类型/版本/文档/能力；启用。
- Connections：名称/Connector/凭证/项目/状态/最近测试。
- Credentials：provider/scopes/过期/最后使用/状态；不显示 secret。
- 操作：创建/编辑/测试/轮换/撤销/删除（影响检查）。
- 测试：真实轻量调用；结果分类；不记录 secret。
- 状态：未测试/正常/认证失败/过期/禁用。
- 安全：权限/审批；高风险凭证需管理员。
- 窄屏：卡片/全屏表单。

## 4. Capability Registry

路由：`/registry`、`/registry/:id`。

- 列表：类型/名称/版本/状态/风险/所有者/绑定数/更新时间。
- 过滤：类型/可见性/状态/风险/标签。
- 详情：schema/示例/权限/依赖/绑定/文档/版本历史。
- 关系图：依赖/被依赖/绑定/入口；影响分析。
- 绑定：入口类型/权限/审批/预算/启用；入口独立。
- 操作：注册/发布/禁用/删除（依赖检查）。
- 与 Designer/Agent Center/MCP Center 联动。
- 状态：草稿/已验证/已发布/废弃/禁用。
- 详见 [能力注册中心](../08-platform/capability-registry.md)。

## 5. Settings

路由：`/settings/*`。

| 子页 | 内容 |
| --- | --- |
| Profile | 名称/头像/语言/时区/偏好 |
| Security | 密码/MFA/会话/API Token |
| Members | 成员/邀请/角色/状态 |
| Roles | 角色/权限点（自定义） |
| Models | Provider/模型/预算/健康检查 |
| Workspace | 名称/成员/默认项目/配额 |
| Deployment | Local/Private/SaaS/Hybrid 状态/Worker |
| Notifications | 审批/失败/发布/系统 |
| Audit | 审计查询/导出 |
| About | 版本/许可/NOTICE/支持 |

- 语言：默认 `ja`；可选 `en`/`zh`；用户/工作区覆盖。
- 危险操作：删除工作区/撤销 token/轮换凭证需确认/step-up。
- 权限：按角色显示；只读视图。
- 窄屏：二级导航折叠；表单单列。

## 6. 全局状态（这些页面）

| 状态 | 表现 |
| --- | --- |
| 权限 | 403 + 请求访问 |
| 空 | 引导/创建/文档 |
| 加载 | 骨架 |
| 离线 | 本地可用/云禁用 |
| 冲突 | 版本/权限冲突；对比/重试 |
| 过期 | 凭证/审批/SLA；修复链接 |

## 7. 验收

- Approval：批准/拒绝/委派/超时/批量限制/step-up/审计。
- Overview：指标/列表/权限/离线。
- Connections：创建/测试/轮换/撤销/影响检查。
- Registry：绑定/关系图/影响分析。
- Settings：语言/权限/模型/部署/审计。
- 三语/窄屏/键盘/屏幕阅读器。
