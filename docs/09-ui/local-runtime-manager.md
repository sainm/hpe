# Local Runtime Manager

> 路由：`/local`（本地运行时管理）。本地 UI 也可独立打开；默认日语。管理本地运行时、同步、模型、更新、诊断。

## 1. 概览

```text
┌──────────────────────────────────────────────────────────────┐
│ Local Runtime [Running] | バージョン | 更新 | 診断 | 停止     │
├──────────────────────────────┬───────────────────────────────┤
│ 状態                         │ クイック統計                  │
│ 接続/ポート/DB/サンドボックス │ Skills/Workflows/Executions   │
│ モデル/ディスク/更新         │ 最終同期/エラー               │
├──────────────────────────────┴───────────────────────────────┤
│ タブ: Skills | Agents | MCP | Workflows | Sync | Logs | Model │
└──────────────────────────────────────────────────────────────┘
```

- 状态：Running/Degraded/Stopped/Updating；离线徽标。
- 快速统计：本地 Skill/Workflow/Agent/MCP 数；今日执行；失败；磁盘。
- 诊断：端口/权限/沙箱/模型/DB/依赖；可操作建议。

## 2. Skills

- 本地 Skill 列表：名称/版本/信任/状态/更新时间/上次执行。
- 操作：导入（目录/zip）、启用/禁用、测试、导出、删除（依赖检查）。
- 详情：路径/权限/脚本/依赖/签名；打开 Skill Center。
- 不可信 Skill：警告/容器要求/审批。

## 3. Agents

- 本地 Agent 列表：名称/版本/模型/状态。
- 操作：创建/导入/测试/启用；模型可用性检查。
- 无模型模式：仅确定性 Workflow/Skill；提示。

## 4. MCP

- 本地 MCP Server：启动/停止/端口/工具/令牌。
- 外部 Server：连接/状态/工具。
- 操作：添加 stdio/HTTP；测试；生成客户端配置（Claude/Copilot/Codex）。
- 能力令牌：创建/撤销/过期；绑定工作区/工具。

## 5. Workflows

- 本地 Workflow/版本：状态/最近执行。
- 操作：打开 Designer、运行、导出、删除。
- 存储位置/大小；清理草稿。

## 6. Sync

- 连接状态：未登录/已连接/离线；账号/租户/工作区。
- 同步内容：Registry/已发布版本/市场；草稿默认不同步。
- 方向/时间/冲突；手动同步/暂停。
- 冲突：对比/保留本地/采用远端/另存。
- 隐私：不同步 secret/执行数据（可配置审计摘要）。
- 离线队列：待同步项/重试。

## 7. Model Providers

- 本地：Ollama/llama.cpp/OpenAI 兼容；endpoint/model/健康检查。
- 云：LiteLLM/Provider；API key（keychain）；预算/限流。
- 无模型：确定性模式；提示能力限制。
- 测试连接/模型列表/上下文限制。
- 隐私：本地推理不出网；云调用提示数据边界。

## 8. Logs/Diagnostics

- 日志：级别/模块/时间；搜索/下载；脱敏。
- 审计：本地 JSONL；查看/导出。
- 诊断：`hisha doctor` 输出；端口冲突/权限/依赖/沙箱/模型/磁盘。
- 支持包：脱敏日志/配置/版本；用户确认后导出。

## 9. 更新

- 当前版本/最新版本/渠道（stable/beta）。
- 下载/校验/安装/回滚；签名验证。
- 更新前备份/迁移；运行中执行提示。
- 不静默更新；可配置通知。

## 10. 状态

| 状态 | 表现 |
| --- | --- |
| Running | 正常 |
| Degraded | 某依赖不可用（模型/沙箱）；功能降级 |
| Stopped | 启动/诊断 |
| Updating | 进度/回滚 |
| Offline | 本地可用；同步/市场禁用 |
| Permission | 目录/端口/模型权限；修复建议 |

## 11. 窄屏（607px）

- 概览卡片化；Tabs 横向滚动。
- 列表卡片化；详情全屏。
- 更新/诊断/同步主操作固定底部。
- 触控 ≥44px。

## 12. 验收

- 启动/停止/诊断/更新/回滚。
- 本地 Skill/Workflow/Agent/MCP 管理。
- 离线运行；同步冲突/恢复。
- 模型可用性/无模型模式。
- 日志/审计/支持包脱敏。
- 三语/窄屏/键盘。
