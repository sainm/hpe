# Execution Monitor

> 路由：`/executions`（列表）、`/executions/:id`（详情）。覆盖 Workflow 执行、Agent 会话、ToolCall、审批与产物。

## 1. 列表

- 视图：表格（默认）/卡片；实时刷新可暂停。
- 列：Execution ID、Workflow/Agent、版本、状态、触发者/触发器、开始/耗时、节点数、成本、Worker、错误摘要。
- 过滤：状态/类型/时间/Workflow/版本/触发者/Worker/错误码；搜索 ID。
- 排序：开始时间/耗时/成本。
- 批量：取消/导出（权限）。
- 状态：QUEUED/RUNNING/WAITING_APPROVAL/WAITING_SIGNAL/SUCCEEDED/FAILED/TIMED_OUT/CANCELLED。
- 空状态：运行一个 Workflow/文档。

## 2. 详情布局

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Executions | #exec_... [FAILED] | 取消 再実行 エクスポート │
├──────────────────────────────┬───────────────────────────────┤
│ 概要                         │ タブ                          │
│ Workflow/Version             │ タイムライン / ノード / ログ   │
│ 入力/出力                    │ エラー / 成果物 / 承認         │
│ 期間/コスト/Worker           │                               │
│ トレース                     │                               │
├──────────────────────────────┴───────────────────────────────┤
│ イベントストリーム/フッター（follow/stop）                   │
└──────────────────────────────────────────────────────────────┘
```

- 左侧概要固定；右侧 Tab；底部实时事件可选。
- 顶部：取消/重跑/从节点恢复/导出/复制 ID；权限/状态限制。

## 3. 概要

- 状态/原因（失败/取消/超时/审批拒绝/预算）。
- Workflow/Agent + 版本；触发方式/触发者；租户/项目。
- 开始/结束/耗时；节点数/成功/失败/跳过。
- 输入/输出摘要（可展开）；大对象引用。
- 成本/Token/工具调用；Worker/本地。
- traceId/日志/审计链接。
- 关联：父/子执行、AgentSession、Approvals、Artifacts。

## 4. 时间线

- 行：节点/attempt/开始/结束/耗时/状态/重试/审批/错误。
- 缩放/滚动；点击定位节点/日志；过滤节点/状态。
- 并行分支泳道；循环迭代分组。
- 实时更新；暂停/follow。
- 失败/重试/补偿/审批标记。

## 5. 节点

- 列表：nodeId/type/status/attempt/耗时/输入/输出/错误。
- 详情：输入/输出/日志/Artifact/权限/重试。
- 操作：重跑节点/从节点恢复（策略）；取消。
- 敏感字段脱敏；大对象下载。

## 6. 日志

- 级别/节点/时间过滤；搜索；follow/pause。
- 截断提示；下载；不显示 secret。
- 错误堆栈仅服务端/管理员可见（可配置）。
- 与事件/时间线关联。

## 7. 错误

- code/message/node/path/attempt/remediation。
- 重试/补偿/人工处理建议。
- 上游错误（HTTP/DB/MCP）分类；可重试标志。
- 复制错误报告（脱敏）。

## 8. 审批

- 待审批/已批准/拒绝/超时；审批人/时间/评论/表单。
- 链接到 Approval Center；不可在此绕过策略（按权限可审批）。
- 审批影响/风险/参数摘要。

## 9. 产物

- 文件列表：名称/类型/大小/哈希/创建时间/保留期。
- 预览（文本/图片/PDF 按类型）；下载；删除（权限）。
- 来源节点/执行；内容寻址。

## 10. 操作

| 操作 | 条件 |
| --- | --- |
| 取消 | QUEUED/RUNNING/WAITING；权限 |
| 重跑 | 失败/完成；新 Execution；幂等提示 |
| 从节点恢复 | 标准运行时检查点/策略；不适用于不可恢复副作用 |
| 导出 | JSON/审计/日志；权限 |
| 分享 | 深链；权限检查 |
| 审批 | 有权限的审批人；step-up |

## 11. 状态

| 状态 | 表现 |
| --- | --- |
| 加载 | 骨架 |
| 空 | 运行/文档 |
| 权限 | 403/请求访问 |
| 实时断线 | 重连/暂停；不丢历史 |
| 事件过多 | 虚拟化/分页/过滤 |
| 大对象 | 引用/下载；不阻塞 |
| 已删除/归档 | 只读/保留期提示 |

## 12. 窄屏（607px）

- 概要卡片化；Tab 横向滚动。
- 时间线纵向列表；节点详情全屏。
- 日志全屏；搜索/过滤可折叠。
- 主操作固定底部；触控 ≥44px。

## 13. 验收

- 列表/详情/时间线/日志/错误/产物/审批完整。
- 实时事件断线重连；历史可分页。
- 取消/重跑/恢复/导出权限正确。
- 敏感字段脱敏；大对象不阻塞。
- 三语/窄屏/键盘/屏幕阅读器。
