# Skill Center

> 路由：`/skills`（列表）、`/skills/:id`（编辑器）、`/skills/:id/test`（测试控制台）。默认日语；Skill 格式遵循 Agent Skills 标准。

## 1. 列表

- 视图：表格/卡片；列：名称、版本、状态、信任、许可、脚本/参考数、最近更新、所有者、安装/使用次数。
- 过滤：状态/信任/许可/来源/标签；搜索。
- 操作：创建、导入（目录/zip/URL）、导出、克隆、发布、禁用、删除。
- 空状态：创建/模板/从市场安装/文档。
- 信任徽标：official/verified/community/untrusted。

## 2. 编辑器布局

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Skills | 名称 [Draft] | 保存 検証 テスト 公開 エクスポート │
├──────────────┬───────────────────────────────┬───────────────┤
│ ファイル     │ エディタ                      │ プレビュー/   │
│ SKILL.md     │ SKILL.md / reference / script │ 検証/権限     │
│ references/  │                               │               │
│ scripts/     │                               │               │
│ assets/      │                               │               │
│ hpa.skill  │                               │               │
├──────────────┴───────────────────────────────┴───────────────┤
│ テスト/出力/ログ/成果物                                     │
└──────────────────────────────────────────────────────────────┘
```

- 左文件树；中间编辑器（Monaco）；右侧预览/校验/权限。
- 顶部：保存/校验/测试/发布/导出/版本。
- 底部：测试控制台（可折叠/全屏）。

## 3. 表单/文件

### 基本情報

- name（标准，≤64）、description（≤1024，触发说明）、license、compatibility、tags、版本（semver）。
- 信任/来源/签名状态（只读）。

### SKILL.md

- YAML frontmatter 编辑器 + 正文 Markdown。
- 原文模式/表单模式切换；表单只编辑标准字段，不改正文结构。
- 预览：Markdown 渲染；引用文件链接。
- 校验：frontmatter/长度/路径。

### references/

- 文件列表/上传/新建/删除；Markdown/文本/PDF 等。
- 引用关系；按需加载提示；大小限制。
- 不在 SKILL.md 中内联大段参考。

### scripts/

- 文件列表；语言/运行时/超时/网络/资源声明。
- 脚本编辑器；语法检查；参数/输出约定。
- 脚本清单（`hpa.skill.json`）同步；不可指向外部路径。
- 运行测试；沙箱日志。

### assets/

- 上传/预览/删除；MIME/大小；不执行。
- 模板/字体/图片；许可/来源。

### 扩展清单

- `hpa.skill.json` 可视化编辑：entry/scripts/permissions/dependencies/tests/trust。
- 与标准字段冲突时提示；未知字段保留。
- 签名/版本/发布状态。

### 依存/権限

- Skill/脚本包/连接器依赖；版本范围/冲突。
- 文件/网络/命令/环境/资源；风险提示。
- 权限变更需确认；发布时校验。

## 4. 测试控制台

```text
┌──────────────────────────────┬───────────────────────────────┐
│ 入力 (JSON/ファイル)         │ 実行結果                      │
│ モック (モデル/ツール)       │ stdout/stderr/成果物          │
│ [実行] [停止]                │ アサーション/カバレッジ       │
└──────────────────────────────┴───────────────────────────────┘
```

- 模式：Deterministic（脚本）/Agent-guided（mock 模型）/Hybrid。
- 输入：JSON/文件/表单；测试用例保存。
- Mock：模型响应/工具结果/错误/延迟；不触达真实外部系统（除非显式）。
- 断言：exitCode/stdout schema/artifacts/工具调用。
- 运行：沙箱；超时/资源；日志/产物。
- 覆盖率：脚本/分支（可行时）；不伪造。
- 回归：版本变更后重跑；失败阻止发布（可配置）。

## 5. 导入/导出

### 导入

1. 选择目录/zip/URL/市场。
2. 预览文件/frontmatter/脚本/权限/许可。
3. 校验/扫描；信任标记；依赖解析。
4. 生成草稿；不自动启用。
5. 测试 → 发布。

### 导出

- 标准目录 + 可选 `hpa.skill.json`。
- 清理本地路径/内部字段；保留许可/NOTICE。
- 客户端安装说明：Claude Code/Codex/VS Code/Copilot。
- 签名/校验和；拒绝专有/无许可。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 空 | 创建/模板/导入 |
| 加载 | 骨架 |
| 解析错误 | 文件/行号/修复 |
| 校验失败 | 错误列表/定位 |
| 权限 | 403/请求访问 |
| 只读 | 已发布/无权限 |
| 测试中 | 日志/停止/超时 |
| 离线 | 本地可用；市场/同步禁用 |
| 冲突 | 版本/文件冲突；对比/另存 |

## 7. 窄屏（607px）

- 文件树/编辑器/预览一次显示一个；Tabs 切换。
- 测试控制台全屏；日志可读。
- 顶部只保留返回/名称/测试/菜单。
- 上传/文件操作触控友好。

## 8. 验收

- 创建/导入→校验→测试→发布→导出闭环。
- 标准目录/ frontmatter 兼容；未知字段保留。
- 沙箱/权限/路径/脚本安全。
- 离线测试/执行。
- 外部客户端加载导出包（PoC B）。
- 三语/窄屏/键盘/屏幕阅读器。
