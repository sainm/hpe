# Workflow Designer

> 路由：`/w/:workspace/p/:project/workflows/:id/designer?version=draft|<version>`。默认日语 UI；术语保留英文。

## 1. 布局

```text
┌──────────────────────────────────────────────────────────────────────┐
│ ← 返回 | 名称 [草稿] | 保存 検証 実行 公開 | バージョン | YAML JSON AI │
├──────────┬───────────────────────────────────────────┬───────────────┤
│ Palette  │ Canvas                                    │ Inspector     │
│ 検索     │  Start → HTTP → 条件 → 承認 → End         │ 設定/入出力/  │
│ カテゴリ │  [ズーム] [ミニマップ] [自動整列]          │ 変数/再試行/  │
│ お気に入 │                                           │ タイムアウト/ │
│          │                                           │ エラー/権限   │
├──────────┴───────────────────────────────────────────┴───────────────┤
│ Debugger: 入力 | 出力 | ログ | エラー | タイムライン | 成果物        │
└──────────────────────────────────────────────────────────────────────┘
```

- 三栏可调；Palette 280、Inspector 360、Debugger 240。
- 顶部固定；画布独立滚动；保存/校验/运行状态始终可见。

## 2. 顶部栏

| 控件 | 行为 |
| --- | --- |
| 返回 | 有未保存修改时确认（保存/放弃/取消） |
| 名称 | 就地编辑；重名/长度校验 |
| 状态 | 草稿/已发布/只读；版本选择器 |
| 保存 | 自动保存 + 手动；显示保存中/已保存/冲突 |
| 校验 | 运行五类校验；错误列表/画布高亮 |
| 运行 | 输入表单 → 执行；`Cmd/Ctrl+Enter` |
| 公开 | 校验通过 + 权限 + 变更摘要；不可跳过错误 |
| YAML/JSON | 打开侧面板/全屏编辑器；与画布同步 |
| AI 生成 | 对话框（描述→预览→校验→应用草稿） |
| 更多 | 复制、导出、删除、版本历史、设置 |

## 3. 左侧 Palette

- 搜索（名称/关键词/描述）；防抖。
- 分类：Trigger、Control、Data、Integration、AI、Human、System。
- 收藏/最近使用；项目常用。
- 节点卡片：图标、名称、描述、风险徽标；拖拽到画布。
- 节点详情 popover：输入/输出/权限/文档/示例。
- 空结果：建议搜索词/文档。
- 窄屏：抽屉；点击“+”添加。

## 4. 画布

### 节点

- 形状：矩形卡片；容器（Loop/Parallel）为可展开区域。
- 内容：图标、名称、类型/版本徽标、状态点、错误/警告徽标。
- 端口：输入左、输出右/下；命名端口显示标签（true/false/case）。
- 选中：2px primary 边框；多选/框选。
- 拖拽/对齐/分布/自动布局；网格吸附（可关）。
- 复制/粘贴/删除/禁用；撤销/重做。
- 节点右键：运行到此、从此运行、复制、禁用、查看文档、删除。
- 版本徽标：非最新 typeVersion 显示提示/迁移。

### 连线

- 从端口拖到端口；校验类型/端口；非法连接红色提示。
- 连线选中/删除；标签（条件端口）。
- 分支节点：true/false 或多 case；默认端口必须存在（按配置）。
- 连线不承载表达式；条件在节点配置。

### 画布工具

- 缩放（10%-200%）、适应视图、100%。
- 平移（空格拖拽/中键）。
- MiniMap；可折叠。
- 自动布局（Dagre/ELK 候选；PoC 验证）。
- 分组/注释；可折叠。
- 执行覆盖：运行中节点脉冲、成功/失败色、耗时；可关闭。
- 搜索节点（Cmd/Ctrl+F）；定位。
- 只读模式：禁止编辑，允许查看/运行（按权限）。

### 画布状态

| 状态 | 表现 |
| --- | --- |
| 空 | 引导：添加 Start/模板/AI 生成 |
| 加载 | 骨架/进度；不闪白 |
| 校验错误 | 节点/边红点；底部错误列表；定位 |
| 冲突 | 顶部横幅；对比/重新加载/另存 |
| 只读/权限 | 横幅；隐藏编辑；解释 |
| 离线 | 顶部徽标；本地可用；云功能禁用 |
| 运行中 | 覆盖状态；可取消；底部实时事件 |

## 5. 右侧 Inspector

Tabs：

1. **設定**：节点名称/描述/类型/版本/配置（SchemaForm）。
2. **入力**：输入映射（jq/模板）；上游输出选择器；预览。
3. **出力**：输出 schema/示例；下游可用字段。
4. **変数**：可见作用域/变量；`setVariable` 提示。
5. **再試行**：maxAttempts/backoff/jitter/retryOn。
6. **タイムアウト**：节点/容器/执行。
7. **エラー**：fail/skip/continue/fallback/compensate；fallback 端口。
8. **権限**：网络/文件/命令/连接器/模型/MCP；风险。
9. **ドキュメント**：节点文档/示例/错误码。

交互：

- 修改即脏；自动保存草稿；字段级校验。
- 表达式编辑器：Monaco + 变量补全 + 预览；错误定位。
- 权限变更需确认（发布时也会校验）。
- 版本升级：显示迁移/差异；不可自动迁移提示。
- 只读：显示值，禁用编辑。
- 底部“应用/重置”（可选；默认即时保存）。

## 6. 底部 Debugger

Tabs：入力 / 出力 / ログ / エラー / タイムライン / 成果物。

- 输入：表单（来自 inputs schema）；保存测试用例；最近输入。
- 输出：节点/执行输出树；复制/下载。
- 日志：级别/节点过滤；follow/pause；截断提示。
- 错误：code/message/node/path/remediation；重试。
- 时间线：节点开始/结束/耗时/attempt/审批/重试；点击定位节点。
- 成果物：文件/大小/哈希/下载；权限。
- 运行控制：运行/取消/重跑节点/从节点恢复（策略）。
- 历史：选择最近执行；对比。

## 7. YAML / JSON 面板

- 侧面板/全屏；Monaco；语法/诊断。
- 与画布双向同步：语义变化 → 画布更新；解析错误 → 保留上次有效 + 错误。
- 格式化/规范化；`Cmd/Ctrl+S` 保存；`Cmd/Ctrl+Z`。
- 注释/格式保真：见 [YAML/JSON](../03-workflow/yaml-json-schema.md)；UI 显示“文本保真/已规范化”。
- 只读查看（权限）/复制/下载。
- 大文件：虚拟化/分块；避免卡顿。

## 8. AI 生成

- 对话框：需求描述、触发方式、输入/输出、范围/权限；生成。
- 结果：节点/边预览、权限变化、假设/未决；校验问题。
- 操作：应用为草稿/对比/重新生成/取消。
- 不可直接发布；不执行未验证流程。
- 生成中可取消；失败显示可操作错误。

## 9. 快捷键

| 键 | 动作 |
| --- | --- |
| `Cmd/Ctrl+S` | 保存 |
| `Cmd/Ctrl+Enter` | 运行 |
| `Cmd/Ctrl+K` | 命令面板 |
| `Cmd/Ctrl+F` | 搜索节点 |
| `Cmd/Ctrl+Z` / `Shift+Z` | 撤销/重做 |
| `Delete` | 删除选中 |
| `Space` + drag | 平移 |
| `Cmd/Ctrl+0` | 适应视图 |
| `Esc` | 关闭面板/取消选择 |

## 10. 窄屏（607px）

- Palette/Inspector 全屏抽屉，一次一个。
- 画布占满；顶部只保留返回/标题/运行/菜单。
- Debugger 变底部 Tab；可全屏；日志/时间线可读。
- YAML/JSON 全屏；切换画布有提示。
- 主操作固定底部；触控目标 ≥44px。
- 验证：节点拖拽/连线/配置/运行/审批/错误定位。

## 11. 验收

- Canvas/YAML/JSON 往返语义一致（fixture）。
- 校验错误可定位到节点/字段；修复后消失。
- 运行/取消/重试/审批/恢复可用；事件实时。
- 只读/权限/离线/冲突状态正确。
- 三语/窄屏/键盘/屏幕阅读器检查。
- 无硬编码文案；无未保存丢失。
