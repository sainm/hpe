# Plugin Marketplace

> Phase 5 本地实现说明：当前使用单页 `/plugins` 的「インストール済み / マーケットプレイス」两个标签，没有独立 `/marketplace/:id` 路由；详情在列表右侧展示。下方是完整产品形态的目标规格，未实现的独立详情路由、审核工作流后台、发布者主页与付费/分成不在本地 MVP 范围。
>
> 路由：`/marketplace`（发现）、`/marketplace/:id`（详情）、`/plugins`（已安装）。默认日语。

## 1. 发现页

- 顶部：搜索、类型（Plugin/Skill/Template/MCP）、分类、信任、许可、兼容版本。
- 推荐/趋势/新上架/编辑精选（标注）。
- 卡片：名称、摘要、类型、发布者、信任徽标、版本、评分、下载、许可。
- 空结果：建议/清除过滤。
- 不展示未审核/被撤回内容。

## 2. 详情页

```text
┌──────────────────────────────────────────────────────────────┐
│ ← Marketplace | 名称 [Verified] | インストール | バージョン   │
├──────────────────────────────┬───────────────────────────────┤
│ README/スクリーンショット     │ 権限/依存/互換性/ライセンス    │
│ 变更日志/バージョン           │ 评分/レビュー/举报             │
├──────────────────────────────┴───────────────────────────────┤
│ インストール/アップグレード/ロールバック                     │
└──────────────────────────────────────────────────────────────┘
```

内容：

- 名称/摘要/类型/发布者/信任/版本/更新日。
- README/截图/示例/文档/支持链接。
- 权限清单：网络/文件/凭证/命令/资源；风险说明。
- 依赖/兼容性（Hisha 版本/OS/运行时）。
- 许可/NOTICE/签名/来源。
- 变更日志/版本历史；破坏性变更标注。
- 评分/评论/举报。

## 3. 安装/升级

流程：

1. 选择版本（最新稳定/指定）。
2. 解析依赖/冲突/兼容性。
3. 展示权限/许可/信任/变更。
4. 管理员批准（按策略）；用户确认。
5. 签名/扫描/安装；能力进入草稿/启用。
6. 试运行/回滚。

升级：

- 变更日志/权限差异/破坏性变更。
- major 需确认；不自动升级。
- 保留旧版本执行；迁移提示。
- 回滚。

## 4. 已安装

- 列表：名称/版本/状态/权限/更新可用/安装者/时间。
- 操作：启用/禁用/升级/回滚/卸载/查看能力。
- 依赖影响：卸载前检查。
- 权限审计：最近使用/异常。

## 5. 评分/评论

- 安装/使用后可评分（可选验证）。
- 评论：文本/评分/版本；举报/审核。
- 发布者可回复；不删除负面（除违规）。
- 防刷/去重。

## 6. 状态

| 状态 | 表现 |
| --- | --- |
| 加载 | 骨架 |
| 空 | 清除过滤/推荐 |
| 未审核 | 不展示/仅链接 |
| 不兼容 | 禁用安装/说明 |
| 许可限制 | 禁止/警告 |
| 权限过高 | 需管理员 |
| 更新中 | 进度/回滚 |
| 撤回 | 禁用/通知 |

## 7. 窄屏（607px）

- 卡片单列；过滤抽屉；详情 Tabs。
- 安装/升级固定底部；权限全屏。
- 评论分页/折叠。

## 8. 验收

- 搜索/过滤/详情/安装/升级/回滚/卸载。
- 权限/许可/信任/签名/兼容性展示正确。
- 依赖冲突/影响分析。
- 撤回/禁用/审计。
- 三语/窄屏/键盘。
