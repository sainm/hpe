# Marketplace

> Marketplace 分发插件、Skill 与模板。它不是无审核的 npm：每个包都要有许可、签名、权限、审核与撤回机制。

## 1. 范围

| 类型 | 内容 | 安装后 |
| --- | --- | --- |
| Plugin | Node/Connector/Tool/Skills/Agents/MCP 配置 | 注册能力、权限确认 |
| Skill | 标准 Agent Skills 目录 | 进入 Skill Registry/可导出 |
| Template | Workflow/Agent/项目模板 | 创建草稿，不自动发布 |
| MCP Server | 连接配置/工具清单 | 注册外部 Server（凭证引用） |

Phase 1 不做付费/分成；Phase 6 再评估计费。

## 2. 列表/详情

列表：

- 名称/摘要/类型/发布者/版本/信任等级/许可/评分/下载量/更新时间。
- 筛选：类型/分类/信任/许可/兼容版本/标签。
- 搜索：名称/描述/能力/标签；不搜索私有租户内容。

详情：

- README/文档/示例/变更日志。
- 权限清单（文件/网络/凭证/命令/资源）。
- 依赖/兼容性/版本历史。
- 许可/NOTICE/来源/签名。
- 评分/评论/举报。
- 安装/升级按钮（按权限）。

## 3. 安装/升级

1. 选择版本（默认最新稳定；major 需确认）。
2. 解析依赖/兼容性；冲突报错。
3. 展示权限差异/许可/信任；管理员批准（如需要）。
4. 签名/完整性校验；扫描。
5. 安装到工作区；能力进入草稿/启用。
6. 试运行/回滚。

升级：

- 展示变更日志/权限差异/破坏性变更。
- 保留旧版本能力执行；迁移提示。
- 回滚到旧版本；不可逆迁移警告。

## 4. 审核

自动：

- manifest/schema/结构/路径/文件大小。
- 许可/依赖/SBOM/漏洞。
- 危险模式（网络/文件/命令/混淆）。
- 权限合理性/过度请求。
- 文档/示例完整性。

人工（高风险/官方/推荐）：

- 代码/脚本审查；数据流；权限最小化；品牌/隐私。
- 测试安装/升级/卸载。
- 许可/归属。

拒绝/下架原因：恶意、侵权、未声明权限、危险脚本、虚假描述、无法复现。

## 5. 信任/评分

- 信任：official/verified/community/untrusted；与 Skill 一致。
- 评分：安装/使用/失败/举报；防刷。
- 评论：需购买/安装验证（可选）；举报/审核。
- 推荐：编辑精选/趋势；标注“赞助”（如未来）。

## 6. 许可

- 每个包必须声明 license；市场展示。
- 禁止专有/无许可内容公开分发。
- Apache/MIT 保留 NOTICE/版权；CC-BY 署名。
- 依赖许可扫描；不合规阻止发布。
- 用户安装时确认许可义务。

## 7. 安全/撤回

- 签名/哈希/发布者验证。
- 漏洞/恶意报告 → 隔离/下架/通知。
- 撤回列表；已安装版本禁用/升级提示。
- 审计安装/升级/卸载/权限。
- 供应链：SBOM/来源/构建可追溯。

## 8. 运营

- 发布者账号/验证/密钥管理。
- 审核 SLA/责任/申诉。
- 指标：安装/活跃/失败/举报/撤回/升级率。
- 兼容矩阵：Hisha 版本/OS/运行时。
- 文档/支持联系方式。

## 9. 非目标

- 不做无审核的任意代码市场。
- 不自动执行安装包中的脚本。
- 不允许绕过 Hisha 权限/审批。
- 不在 Phase 1 做付费/分成/税务。
